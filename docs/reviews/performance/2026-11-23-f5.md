## Conclusion and limits

Strong evidence localizes the principal observed delay to loading the development frontend module graph before API startup. Eager locale imports and thousands of HTTP/1.1 module requests are concrete contributors; substantial per-request pre-send waiting was observed. The exact causal share of locale loading vs other modules, browser/extension overhead, server proxy and execution is not yet isolated.

NOT_RUN: controlled code/config A/B, production-build comparison, clean browser profile comparison, complete untruncated waterfall, full CPU trace and load test.
